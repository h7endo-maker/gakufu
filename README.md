# がくふ プレーヤー

娘のピアノ練習用の楽譜再生アプリ。iPadのホーム画面に追加して使う。

- 楽譜データ（MusicXML / .mxl）を開くと、楽譜を表示して音を鳴らす
- テンポ変更、右手だけ・左手だけ、鳴っている音符の色付け、小節を選んでくりかえし
- 複数ファイルをまとめて選ぶと、ファイル名の順につなげて1曲にする
- 楽譜データはiPadの中（ブラウザの保存領域）にだけ保存され、外部には送られない

## ファイル
- `index.html` … アプリ本体
- `sw.js` … オフラインで動かすための仕組み（更新時は VERSION を上げる）
- `manifest.webmanifest`, `icons/` … ホーム画面用の名前とアイコン
- `lib/` … 楽譜表示ライブラリ OpenSheetMusicDisplay 2.3.0（BSD-3-Clause）と JSZip 3.10.1（MIT）
